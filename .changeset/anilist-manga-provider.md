Add AniList as a manga metadata source, alongside MangaDex and MyAnimeList. The manga search gains a source selector to pick which provider supplies series metadata (title, description, cover, status) — AniList gives clean english/romaji/native titles and needs no API key — while MangaDex continues to supply the chapters for whichever provider you add the series from. Because AniList needs no configuration, manga search is now always available even before MangaDex or MyAnimeList is set up.
